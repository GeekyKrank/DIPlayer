# DIPlayer

Самостоятельный Windows-плеер для публичных треков SoundCloud. Собственный тёмный интерфейс с оранжевым акцентом, C# / WPF, системный MP3-декодер и вывод звука Windows через NAudio. Проект не связан с SoundCloud.

Интерфейс 0.1.1: чёрная боковая панель, статичные обои, поиск сверху и компактный плеер снизу. В узком окне управление располагается в две строки. Фон не использует blur, анимации или прозрачное системное окно; изображение декодируется один раз шириной 736 px.

## Запуск

1. Рекомендуемый вариант для проверенного серверного режима — **DIPlayer-win-x64.zip**. Распакуйте весь архив. Также подготовлена экспериментальная x86-сборка.
2. Запустите `DIPlayer.exe` внутри распакованной папки. Отдельная установка .NET не требуется. Обе версии проверялись на 64-битной Windows; отдельные замеры прямого и серверного режимов приведены в отчёте.
3. Новая установка уже настроена на HTTPS-каталог DIPlayer в Oracle. Вход слушателя и собственные ключи не нужны. Адрес можно изменить через ⚙.
4. Для личного теста вместо сервера можно импортировать собственный файл ключей через ⚙. Формат: строки `client id: ...` и `client secret: ...`. Ключи сохраняются с Windows DPAPI для текущего пользователя; они не включены в EXE.

Проверено на Windows 11 x64; требуется системный MP3-кодек и аудиоустройство. Сборка не подписана сертификатом издателя. ARM64 и отдельная 32-битная ОС не проверялись.

## Управление

- Поиск сверху: начните вводить название или автора, либо нажмите Enter. Старый запрос отменяется. Страницы переключаются кнопками ‹ и ›.
- Двойной щелчок или «▶ Играть» запускает выбранный трек. Он добавляется в очередь; «+ В очередь» добавляет без переключения.
- В очереди доступны удаление и изменение порядка кнопками ↑ / ↓. Предыдущий и следующий треки берутся из очереди.
- «Плейлисты»: создать, переименовать, удалить, добавить трек, убрать и изменить порядок. Большие списки читаются из SQLite страницами по 25 строк.
- «Импорт по ссылке»: полный публичный адрес `https://soundcloud.com/автор/sets/плейлист`. Показывается прогресс, недоступные записи отмечаются в списке. При отмене или ошибке сохраняется полученная часть с отметкой незавершённого импорта. Это копия списка, а не скачивание музыки.
- Ползунок позиции перематывает трек; после сетевого сбоя кнопка «Повторить» обновляет поток и возвращает позицию.
- Закрытие и сворачивание окна скрывают его в трей. Двойной щелчок по значку открывает окно. Полный выход — через меню трея.
- Мультимедийные клавиши: воспроизведение/пауза, следующий, предыдущий, остановка. Глобальная регистрация может конфликтовать с другим плеером. Windows SMTC-карточка сейчас не реализована.

## Данные и ограничения

Библиотека, очередь и настройки находятся в `%LOCALAPPDATA%\DIPlayer`. В `library.db` сохраняются локальные названия плейлистов, ID треков и порядок; метаданные обновляются страницами через API. Без сети список ID сохраняется, но загрузка названий и обложек недоступна. Очередь ограничена 1000 записями. Для резервной копии закройте приложение через трей и скопируйте папку данных. При работе SQLite использует также WAL-файлы.

Работает проверенный путь **MP3 HLS VOD**. AAC-only, live, зашифрованные и byte-range HLS потоки отклоняются с сообщением. Аудио не кешируется на диск; максимум один сжатый сегмент до 2 МиБ и PCM-буфер до 4 секунд плюс небольшие декодерные/выходные буферы. Полный трек в память не загружается.

Обложки декодируются в 64 px; кеш в памяти ограничен 64 изображениями, дисковый кеш отключён. Метаданные кешируются в пределах сессии, максимум 128 треков. Таймер позиции работает с частотой 1 Гц только у видимого окна. При скрытии прекращается загрузка обложек и отменяются запросы обновления списка.

Не любой трек доступен внешнему плееру. Приватные плейлисты не импортируются. Preview не выдаётся за полный трек. Если API сообщает только `blocked` или HTTP 403, приложение не угадывает, вызвано ли это регионом, оплатой или запретом автора. Отдельные причины показываются только при явном коде ответа. Платный доступ и региональные ограничения не обходятся.

Обработчики сна и смены устройства реализованы; физические испытания сна/отключения аудиоустройства пока не завершены. RAM/CPU оцениваются по замерам: [результаты и условия](docs/validation.ru.md).

## Сборка

Нужен .NET 10 SDK. На Windows:

```powershell
pwsh -File tools/Build.ps1
```

По умолчанию собирается Windows x64. Для x86 добавьте `-WindowsRid win-x86`. В прямом API-режиме x86 расходовала меньше памяти, но в серверном режиме текущая x64-сборка показала меньший Working Set. Сравнение не следует переносить между режимами.

Сервер для Oracle x64:

```powershell
pwsh -File tools/Build.ps1 -WithServer -ServerRid linux-x64
```

Подробности сервера: [docs/server.ru.md](docs/server.ru.md). Историческая проверка доступа: [docs/feasibility.ru.md](docs/feasibility.ru.md).

Не публикуйте `clientAPI.txt`, `.env`, `secrets.env`, локальные настройки, токены или SSH-ключи. Публичная сборка обращается к серверу, который хранит секрет SoundCloud. Квоты сервера общие и ограничены; масштабирование без проверки тарифов не предусмотрено.

Техническая сборка не означает одобрения продукта SoundCloud. В [условиях API](https://developers.soundcloud.com/docs/api/terms-of-use) есть ограничения на альтернативные сервисы прослушивания и постоянное хранение полученного контента. До массового запуска нужно подтвердить допустимость сценария у SoundCloud. Исходники и экспериментальная сборка не обещают такого разрешения.

## Модули

- `DIPlayer.Core`: каталог, авторизация приложения, поиск, разрешение ссылок, серверный клиент.
- `DIPlayer.Audio`: HLS сегментами, ограниченный PCM-буфер, системный декодер и вывод.
- `DIPlayer`: WPF UI; отдельные модули Import, Queue, Storage, SystemIntegration.
- `DIPlayer.Server`: каталог без выдачи секретов и без аудиопрокси.
- `DIPlayer.Probe` и `DIPlayer.Tests`: реальный аудиопрототип и интеграционные проверки.
